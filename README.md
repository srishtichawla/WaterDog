# 🐶 WaterDog

**A cute macOS hydration reminder that gets angry when you ignore it! 💧**

WaterDog is a fun Python-based desktop companion designed to remind you to drink water throughout the day.

Instead of sending boring notifications, WaterDog makes staying hydrated more interactive. Your virtual dog reminds you to drink water, and if you keep ignoring it, it gets increasingly angry! 😠

## ✨ Features

- 💧 Regular reminders to drink water
- 🐶 A virtual dog with changing moods
- 😠 Gets angry when hydration reminders are ignored
- 🖥️ Runs on macOS
- 🐍 Built using Python

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/srishtichawla/WaterDog.git
cd WaterDog
```

Run the application after installing its required Python dependencies:

```bash
python3 water_dog.py
```
